The Overview

Designed and implements each component for an end-to-end manufacturing robot, primed for 360 degree detection optimised to remove image noise and threshold errors. Robust against orientation and block colour changes.

Tech stack

Modal was used to train policies. Intel’s Core Ultra laptop GPU housed inference and PatchCore detection training / testing. OpenVINO was used to convert models to run on Intel hardware. ACT, transformer-based policy, trained on Teleoperative data. Gemini CLI was used to support coding and set up.

The problem

See it. Detect it. Act on it. The Physical AI challenge asked us to prime a robotic arm to inspect blocks, spotting faulty ones and sort them accordingly, running all from one laptop as edge AI. It was our job to build the environment, the data, the architecture, the training and testing process, and integration.
