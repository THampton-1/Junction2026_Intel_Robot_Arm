The architecture, now that we can see it

One joint at a time, each with a check that must pass before the next.

What we'd do differently

This list is a first draft. Each person should add their own lessons and cut any that don't fit.

Draw the system before building it

Decide who owns each camera and port, and what each part hands the next, on day one. We wrote that down on the last night.

Integrate in small, checked steps

Join one part at a time with a pass/fail check. Never ask anyone, human or AI, to "bring it all together" in one go.

Guard the hardware

Speed and torque limits, a check that calibration is loaded before any move, and an easy power-off. Software mistakes become hardware damage.

Treat AI agents like a new teammate

Give a narrow task, review the changes, and commit what works. Don't let one edit vendor drivers on a live robot unsupervised.

Fail loudly

Our app quietly swapped in fake models when a real one was missing, so it looked alive while doing nothing.

Commit as you go

The session's fixes were lost in a revert because they were never saved.

Never ship placeholder numbers

A report generator filled in invented trial results, and they reached our slides as "15 physical trials". Label anything not measured.

Measure on the target machine

Our final model's speed was only measured on a different laptop.

Use the cloud for training from the start

Our first ACT run spent over 3½ hours on a laptop CPU before we moved it to a cloud GPU.

One source of truth for settings

Camera paths, thresholds and poses disagreed across three files.
